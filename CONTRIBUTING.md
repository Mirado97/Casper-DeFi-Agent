# Contributing to Casper DeFi Agent

Thank you for your interest in contributing! This guide covers the basics.

## Getting Started

1. **Fork** the repository
2. **Clone** your fork locally
3. **Create a feature branch** from `main`
4. **Make your changes** and commit with clear messages
5. **Push** your branch and open a **Pull Request**

## Code Style

- **TypeScript**: Follow strict type checking (`tsconfig.json`)
- **Formatting**: Use Prettier (pre-commit hooks enforce this)
- **Naming**: Use clear, descriptive names for functions and variables

## Testing

- Run tests before submitting: `npm run test`
- Add tests for new features
- Ensure existing tests still pass

## Commit Messages

Use the format: `type: description`

**Types**: `feat`, `fix`, `docs`, `test`, `chore`, `refactor`

Example: `feat: add honeypot detection to Token Safety Oracle`

## Pull Request Process

1. Update `README.md` if needed
2. Add tests for new features
3. Ensure CI passes (GitHub Actions)
4. Request review from maintainers

## Security

If you find a security vulnerability, please **do not** open a public issue. Instead, email us privately at miradonax@gmail.com.
